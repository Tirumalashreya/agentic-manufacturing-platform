# Optimization Service (`services/optimization-service`)

## Overview
The `optimization-service` executes optional, best-effort refinement passes on schedules generated by `scheduling-service`.

## Core Capabilities
- **Load Balancing**: Leveling machine utilization across identical parallel work centers.
- **TSP Setup Optimization**: Heuristic job re-ordering to minimize tool changes.
- **Solver Interface**: Proxies complex combinatorial constraints to `optimization-solver` (Port 4007).
- **Graceful Degradation**: If this service is offline, `scheduling-service` logs a warning and proceeds with the core heuristic schedule without failing.
